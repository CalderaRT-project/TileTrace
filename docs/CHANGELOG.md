# TileTrace 更新日志

## 0.1.5 - 2026-11-25

### 新增

- 为可静态推导的 `tl.load` 增加「分块位置」，显示块内索引对应的行列范围、program 或循环偏移和可识别的掩码边界。

### 变更

- VS Code 面板标签的标题简化为 `TileTrace`。
- 编辑器工具栏和面板标签采用透明底「选中格」图标。深浅主题的 SVG 可供 README 引用。
- 「简约」成为默认视图，每张卡片显示最多 4 行 × 4 列真实坐标。点击输出格查询来源，通过行列起点移动窗口。网格上方可切换「简约」和「普通」视图。

### 修复

- 修复并排显示时输出与来源网格错位的问题。查询坐标和展开来源明细时，网格保持对齐。

## 0.1.4 - 2026-11-24

### 变更

- TileTrace 仅通过 VS Code 扩展提供。VSIX 内置处理静态分析和坐标查询的本地 Python 进程。
- 面板优先展示当前算子、输出坐标和直接来源。参数与普通诊断可按需展开。
- 窄面板可收起步骤列表，宽面板使用侧栏。循环内的步骤按迭代分组，源码切换时列表会定位当前操作。
- 矩阵通过行列头标明坐标，选中输出格后显示完整坐标。来源一栏以范围和可见数量概括对应输入。
- 整理公开更新日志，同一天的更新合并为一个版本。

### 修复

- 自动从工作区虚拟环境和 `PATH` 查找可运行的 Python 3.10+，支持只有 `python3` 命令的环境。
- 分析进程启动失败时显示错误并结束等待提示。

### 移除

- 移除 MCP 服务、复制 Agent 提示词命令、工作区会话快照及 `tiletrace.sessionDirectory` 设置。
- 移除独立分析命令行和 Python wheel 打包入口。

## 0.1.3 - 2026-10-15

### 新增

- 新增可选的「简约」视图。长度大于 4 且能被 4 整除的显示轴，每 4 个连续坐标展示为一组。点击分组可查看真实坐标并查询来源。
- 在编辑器右上角添加 TileTrace 矩阵图标，用于打开变换面板。面板标签使用同一套主题图标。

### 变更

- 变换面板改为手动打开。打开后会随当前 Triton 文件和源码选择更新。

### 移除

- 移除 `tiletrace.autoOpen` 设置。

## 0.1.2 - 2026-10-10

### 变更

- 简化张量卡片，将方向、显示数量和坐标省略说明移到悬停提示。
- 补充 VSIX 安装和可视化面板使用说明。

### 修复

- 张量卡片按网格和控件的实际尺寸调整宽度。输入和输出根据可用空间切换横向或纵向布局，箭头方向随布局更新。

## 0.1.1 - 2026-10-09

### 新增

- 支持二维 `tl.dot` 的行列来源映射、显式类型转换和已知整数边界的 `tl.static_range` 静态展开。
- 添加 FlashAttention 前向示例，展示 Q/K/V 分块、矩阵乘法和在线 softmax 的变换过程。

### 变更

- 长度超过 8 的轴默认展示首尾各 3 个坐标。点击省略号可展开坐标窗口。

### 修复

- 根据新增轴的实际用法，一维行索引纵向排列，列索引横向排列。
- 同一文件的面板刷新会保留页面、操作列表和坐标网格的滚动位置，以及参数区的展开状态与输入焦点。

## 0.1.0 - 2026-10-08

### 新增

- 提供 VS Code 张量变换面板，静态分析 Triton 的 `arange`、新增轴、广播、reshape、转置和归约，并支持点击输出坐标查看直接输入来源。
- 支持读取未保存的编辑、同步源码选择、定位操作表达式和输入分析参数。
- 默认展示关键张量步骤，并将参数和常量折叠到操作详情。勾选「显示全部节点」可查看完整操作列表。
